## 第二步：用 SSH 客户端连接上去

这一步是搬瓦工 VPS 怎么用的核心。

连接需要三个信息：**IP 地址、SSH 端口、root 密码**。前两项在 KiwiVM 面板的 Main Controls 页里能看到，密码就是刚才重置的那个。

工具推荐如下：

- **Windows 用户**：Termius（免费、跨平台、可同步配置，目前首推）或 Xshell（老牌稳定，免费版够用）
- **Mac 用户**：系统自带终端就行，直接打开 Terminal
- **Linux 用户**：直接用命令行，不用装额外工具

**Windows 用 Xshell 连接的步骤：**

1. 打开 Xshell，新建会话
2. 协议选 SSH，主机填你的 VPS IP 地址，端口填 SSH 端口号（不是默认的 22，搬瓦工用的是随机高位端口）
3. 验证方式选「Password」，用户名填 `root`，密码填刚才重置的那个
4. 点连接，看到命令行界面出现，连上了

**Mac / Linux 直接在终端输入：**

bash
ssh root@你的IP地址 -p 端口号


回车后输入密码，进入命令行界面，大功告成。

连上之后你看到的是一个空白的命令行。从这里开始，搬瓦工 VPS 就是你的了，想装什么装什么。

## 流量用完了怎么办？

搬瓦工的流量是按月重置的，重置时间是每个月的固定日期。

流量用完了，VPS 会进入暂停状态，显示「Data transfer limit exceeded」。有两个处理办法：

一是等月份结束自动重置。二是搬瓦工提供「临时恢复」功能，可以在 KiwiVM 面板临时解封，恢复一定量的流量额度继续使用。
